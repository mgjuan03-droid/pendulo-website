The discipline

What is Hyrox?

Hyrox is the World Series of Fitness Racing — run to the same format in every city on earth, so results anywhere feed a single global ranking toward the World Championship.

The format alternates eight 1 km runs with eight functional stations, in this exact order:

  • 01 1 km Run + 1000m SkiErg
  • 02 1 km Run + 50m Sled Push
  • 03 1 km Run + 50m Sled Pull
  • 04 1 km Run + 80m Burpee Broad Jump
  • 05 1 km Run + 1000m Row
  • 06 1 km Run + 200m Farmers Carry
  • 07 1 km Run + 100m Sandbag Lunges
  • 08 1 km Run + 100 Wall Balls

Raced in Open, Pro, Doubles and Relay categories — accessible to first-timers, demanding enough for competitive athletes. It's a fitness race for every kind of body.

On our floor

How we train at Péndulo.

Our training floor at Décima Plaza is built as a Hyrox-style circuit: a sled lane and running track, SkiErgs, rowers, treadmills, a stair climber, free weights and a hip-thrust station — every piece chosen to mirror exactly what you'll face on race day.

Coaches program around the eight stations year-round, so a normal Tuesday session and your next Hyrox heat are built from the same movements.
